# javaProjects
Java SpringaBoot Backend Project

AI-Powered Fitness Tracking Application (Microservices Architecture)

(Spring Boot | Spring Cloud | ReactJS | RabbitMQ | Keycloak | PostgreSQL | Google Gemini API)

Designed and developed a full-stack microservices-based fitness application using Spring Boot and ReactJS.
Implemented multiple microservices including Activity Service, User Service, API Gateway, Config Server, and Service Registry (Eureka).
Enabled users to log activities such as Running, Cycling, and other workouts, with duration and calorie tracking.
Integrated Google Gemini API to generate AI-powered calorie suggestions, performance analysis, and personalized improvement recommendations.
Implemented secure authentication and authorization using Keycloak (OAuth2 + JWT).
Used Spring Cloud Gateway for centralized routing and request filtering.
Implemented asynchronous communication using RabbitMQ (Spring AMQP) for event-driven architecture.
Configured centralized configuration management using Spring Cloud Config Server.
Used PostgreSQL/MySQL for persistent storage with optimized query handling.
Followed RESTful design principles and ensured service scalability and loose coupling.
